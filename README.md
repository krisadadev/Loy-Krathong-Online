# คู่มือติดตั้ง — ลอยกระทงออนไลน์

เว็บลอยกระทงออนไลน์ ใช้ PHP + MySQL/MariaDB เก็บรายชื่อกระทงและคำอธิษฐาน

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด |
| `api.php` | API บันทึก/ดึงรายการกระทง |
| `config.php` | ตั้งค่าเชื่อมต่อฐานข้อมูล (ถ้าไม่มี ให้คัดลอกจาก `config.sample.php`) |
| `config.sample.php` | ไฟล์ตัวอย่างการตั้งค่า |
| `schema.sql` | โครงสร้างตารางฐานข้อมูล (ใช้ Import) |
| `.htaccess` | กันไม่ให้เปิดไฟล์ตั้งค่า/SQL/คู่มือผ่านเว็บ |

## ความต้องการของระบบ

- PHP 7.4 ขึ้นไป (ต้องเปิด extension `mysqli` และ `mbstring`)
- MySQL 5.7+ หรือ MariaDB 10.3+
- Apache หรือ Nginx
- ผู้ใช้ต้องต่อเน็ตได้ (หน้าเว็บโหลดฟอนต์จาก Google Fonts และเพลงจาก YouTube)

## ขั้นตอนติดตั้ง

### 1) วางไฟล์
แตกไฟล์ ZIP ที่ได้รับ แล้วนำไฟล์ทั้งหมดไปวางในโฟลเดอร์เว็บของเซิร์ฟเวอร์ โดยตั้งชื่อโฟลเดอร์ว่า `loy-krathong` (ตั้งชื่ออื่นก็ได้)

- **XAMPP (Windows):** วางที่ `htdocs` ภายในโฟลเดอร์ติดตั้ง XAMPP จะได้ `htdocs\loy-krathong\`
- **โฮสติ้ง / เซิร์ฟเวอร์จริง:** อัปโหลดผ่าน FTP หรือ File Manager ไปที่ `public_html/loy-krathong/` (หรือ web root ของโดเมน)

หลังวางแล้ว ไฟล์ `index.html`, `api.php`, `config.php`, `schema.sql` ต้องอยู่ในโฟลเดอร์เดียวกัน

### 2) สร้างฐานข้อมูล
1. เปิด phpMyAdmin (XAMPP: http://localhost/phpmyadmin)
2. แท็บ **Databases** → ตั้งชื่อ `loy_krathong` → เลือก Collation `utf8mb4_unicode_ci` → **Create**
   (ถ้าเป็นโฮสติ้ง ให้สร้างฐานข้อมูลและผู้ใช้จากแผงควบคุมของโฮสต์ แล้วใช้ฐานข้อมูลนั้น)

### 3) Import ไฟล์ SQL
1. คลิกชื่อฐานข้อมูลที่สร้างไว้ทางซ้าย
2. แท็บ **Import** → **Choose File** → เลือก `schema.sql` → กด **Import**
3. จะได้ตาราง `loy_krathong` 1 ตาราง

หรือใช้คำสั่ง command line:

```
mysql -u root -p loy_krathong < schema.sql
```

> ถ้าต้องการให้ไฟล์สร้างฐานข้อมูลให้เองด้วย ให้เอาเครื่องหมาย `--` หน้า 2 บรรทัด
> `CREATE DATABASE` / `USE` ใน `schema.sql` ออก แล้ว Import จากหน้าหลักของ phpMyAdmin

### 4) ตั้งค่า `config.php`
ถ้ายังไม่มีไฟล์ `config.php` ให้คัดลอก `config.sample.php` เป็นชื่อ `config.php` ก่อน แล้วแก้ค่าให้ตรงกับเซิร์ฟเวอร์:

```php
'host' => 'localhost',
'port' => 3306,
'name' => 'loy_krathong',   // ชื่อฐานข้อมูล
'user' => 'root',           // ผู้ใช้ฐานข้อมูล
'pass' => '',               // รหัสผ่าน
```

- XAMPP ค่าเริ่มต้น: user `root`, รหัสผ่านว่าง (ใช้ได้เลย)
- เซิร์ฟเวอร์จริง: **ห้ามใช้ root** ให้สร้างผู้ใช้เฉพาะที่มีสิทธิ์ `SELECT, INSERT` บนฐานข้อมูลนี้ และตั้งรหัสผ่านที่เดาไม่ได้

### 5) ทดสอบ
- เปิดเบราว์เซอร์ไปที่ `api.php` ในโฟลเดอร์ที่วางไว้ เช่น `http://localhost/loy-krathong/api.php` (XAMPP) หรือ `https://โดเมนของคุณ/loy-krathong/api.php`
  ต้องได้ `{"ok":true,"items":[]}`
- เปิด `http://localhost/loy-krathong/` (หรือ URL ของโดเมนคุณ) ลองลอยกระทง 1 ดวง ใส่ชื่อ แล้วกด "ดูกระทงของทุกคน" ควรเห็นกระทงพร้อมป้ายชื่อ

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| `api.php` ตอบ `{"ok":false,"error":"db"}` | ค่าใน `config.php` ผิด (host/ชื่อ DB/user/รหัสผ่าน) หรือ MySQL ยังไม่เปิด |
| ตอบ `{"error":"table_missing"}` | ยังไม่ได้ Import `schema.sql` หรือ Import ผิดฐานข้อมูล |
| ตอบ `rate_limit` (429) | ลอยเกิน 6 ดวง/นาที ต่อ 1 IP (กันสแปม) รอ 1 นาทีแล้วลองใหม่ |
| ภาษาไทยในชื่อ/คำอธิษฐานเป็น `???` | ฐานข้อมูลไม่ใช่ `utf8mb4` ให้สร้างตารางใหม่จาก `schema.sql` |
| เปิดหน้าเว็บแล้วไม่ขึ้นกระทงของคนอื่น | เปิดไฟล์ `index.html` ตรงๆ จะเรียก API ไม่ได้ ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (`http://...`) |
| เพลงไม่ดัง | เบราว์เซอร์ต้องมีการคลิกก่อนจึงเล่นเสียงได้ และเครื่องต้องเข้า YouTube ได้ ถ้าไม่ได้ ระบบจะใช้เสียงสังเคราะห์แทน |
| Nginx เปิดดู `config.php`/`schema.sql` ได้ | `.htaccess` ใช้กับ Apache เท่านั้น ให้เพิ่ม `location ~ ^/.*/(config\.php\|schema\.sql\|README\.md)$ { deny all; }` |

## การดูแลข้อมูล

- ดูรายการ: phpMyAdmin → ตาราง `loy_krathong`
- ลบกระทงที่ไม่เหมาะสม: `DELETE FROM loy_krathong WHERE id = 123;`
- ล้างทั้งหมด: `TRUNCATE TABLE loy_krathong;`
- สำรองข้อมูล: phpMyAdmin → Export (หรือ `mysqldump -u root -p loy_krathong > backup.sql`)
- หน้าเว็บแสดงกระทงล่าสุด 60 ดวง และรีเฟรชทุก 30 วินาที

## เครดิตเพลง

เพลงประกอบเล่นจากวิดีโอ YouTube “รำวงวันลอยกระทง ดนตรีไทยบรรเลงยาว ๆ | ระนาดเอก” ของช่อง **Fino the Ranad**
(https://www.youtube.com/watch?v=X80o4uXSkOs) ลิขสิทธิ์เป็นของเจ้าของช่อง ระบบฝังเพลงผ่าน YouTube Player อย่างเป็นทางการ และแสดงข้อความขอบคุณที่ท้ายหน้าเว็บเฉพาะหน้าที่เปิดเพลง (ไม่แสดงในหน้าแรก)
หากต้องการเปลี่ยนเพลง ให้แก้ค่า `SONG_ID` ใน `index.html` และข้อความเครดิตที่ท้ายไฟล์ (`id="credit"`)
